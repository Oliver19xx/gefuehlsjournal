# Gefühlsjournal

Eine Journal-App, die mit Hilfe eines Gefühlsrads einlädt, sich zu öffnen: erst das Gefühl benennen, dann mit einem passenden Impuls ins Schreiben kommen und über die Zeit Muster erkennen.

Dieses Repo bündelt die Planung, damit die App an die Entwicklung übergeben werden kann.

## Struktur
- `backlog/` – Produkt-Backlog mit User Stories und Akzeptanzkriterien (Product Owner)
- `flows/` – User Flows, Informationsarchitektur und Wireframes (UX)
- `design/` – Farbsystem, Typografie, Komponenten und Screens (UI)

## Offene Entscheidungen
- Plattform: iOS, Android, beides oder Web-App
